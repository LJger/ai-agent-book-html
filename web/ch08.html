+23~47 pp
“时间感”任务：冻结 Qwen3-32B 教师，在学生自己的多轮轨迹上逐 token 对齐，四种条件下通过率比同源 SFT 基线高 23 到 47 个百分点

      

      
多轮 Agent 的成败信号更晚、更稀疏，逐 token 的教师分布能直接指导中间决策——前提是仿真环境足够真实，否则教师对陌生偏差状态的评分也不可靠

student_trajectory = rollout(model, task_without_answer)loss = 0for state in student_trajectory:    privileged_state = add_verified_answer(state)    teacher_logits = stop_gradient(model(privileged_state))    loss += KL(model(state), teacher_logits)update(model, loss + retention_regularizer)

      

        
相比 RLVR
不要求奖励能被自动验证：特权信息可以是标准答案、人工示范或领域文档；保留“在轨采样 + 逐 token 监督”的样本效率

        
局限
