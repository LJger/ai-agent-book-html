    本章小结：工具设计决定 Agent 的能力上限

    形态
    默认往通用的一端靠

    只在安全权限、参数复杂、使用频率极高、平台差异四种情况下退回专用工具

    与“一次让模型看见多少条”是两个独立的决策：前者定每条能力的常驻成本，后者定同时暴露多少条

    分发
    两条渠道：MCP 与 Skill Hub

    引入一条能力的成本被压到一条命令，也都扩大了信任边界

    审查描述与版本隔离凭证模型看到的参数 = 真正执行的参数
    规模
    层次化组织 → 按需加载 → 主动发现 → Skills

    依次接管：把“选哪个工具”变成“查哪条资料”
