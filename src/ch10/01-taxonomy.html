通信机制：共享内存与消息传递

Agent 之间不共享上下文，就必须通过显式的通信机制传递信息

共享内存一方写入、另一方读取同一块存储
进程间通信（IPC）
归根结底只有两大范式
消息传递把数据显式地发送给对方
工具调用的参数消息传递 · 随调用同步

把下游 Agent 封装成工具，上游 Agent 把结构化数据通过工具参数传给它

适合需要类型确定、结构清晰的场景

共享文件系统共享内存

读写共享目录下的文档、代码等中间产物来交换信息

适合产物较大或需要持久化的场景

消息总线（Message Bus）消息传递 · 经中转站异步

专门在 Agent 之间传递消息的中转站：消息发到总线，由它转发给目标 Agent

特点Agent 不直接调用彼此，发送与投递解耦

Go 语言：「不要通过共享内存来通信，而要通过通信来共享内存」——两种范式各有取舍
