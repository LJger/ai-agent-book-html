PART 07

去中心化模式
与跨组织协作

没有运行时的中心控制者：Agent 之间像人类一样互相沟通
微服务领域把管理者和去中心化模式分别称为编排（orchestration）与编舞（choreography）。

编排与编舞：为什么还要去中心化

模拟人类社会的组织方式

职责对等的角色分工与制衡，各自从专业视角审视问题、自主决定与谁沟通，而不是把所有判断汇集到一个 Manager

稳定性

模型或 API 出问题时，Agent 可能停止响应、工具调用失败、陷入错误调用的死循环；管理者崩溃往往是系统最大的单点故障

编排 vs 编舞

编排：由指挥统一调度；编舞：每位舞者自行把握入场时机

三个案例的递进
MetaGPT伪去中心化：控制流是固定流水线，只在通信机制上解耦
→
AutoGen 群聊共享对话记录 + 中心化调度的混合形态
→
OpenAI Swarm控制流上真正的对等去中心化
