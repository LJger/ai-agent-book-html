前提：Agent 思考时世界静止——这个前提如此自然，以至于很少被当成一个假设写出来 真实环境不会等模型作出反应：这些变化都发生在 Agent 的一个回合之内，它要等这一轮结束才可能看到

两个扩展方向：模态与触发时机

前几章扩展的是两个空间的内容，这一章扩展它们的模态和时机

观察空间的扩展动作空间的扩展
内容第二至五章上下文工程、记忆与知识库工具、代码生成
模态本章语音、屏幕、物理传感器说话、点击、关节运动
时机本章世界主动推送、连续流跨回合、可打断、可抢占
模态决定观察和动作的形式

观察只读文本 → 也能听见声音、看见屏幕、感知力矩

动作只能输出 token → 也能发声、点击、驱动关节

触发时机决定观察和动作的节奏

观察Agent 主动去取 → 世界主动推来

动作回合内做完 → 跨越回合、中途被打断、被更紧急的事抢占
