范式与瓶颈

复用单模态预训练成果，只训一个轻量投影层——高效可扩展，但投影层表达能力有限，可能成为深层理解的瓶颈。再让模型输出动作，就是第六章的 VLA

配套仓库盲评：负结果

原版 SFT 最高 1.9062 / 5；QK-Norm + Muon 版在只训投影层后低 0.1876，完整 SFT 后低 0.6250——两项改动一起变化，无法拆开归因

示意

知识缺口

目标语言、金融 / 医疗 / 法律、企业内部文档、某类代码库——连概念与术语都不能理解

基础能力缺口

长上下文、代码模式、数学推导、跨模态表征——足够多次采样也几乎得不到正确解

为什么不用 SFT 注入知识

少量 QA 只覆盖有限问法，擅长训练“如何访问与表达”；反过来，Mid-training 降了领域 loss，也不保证按问题取得出知识——顺序与数据组织很关键

同预训练的目标与损失，对全部 token 计损；DAPT / TAPT 已证明有效
