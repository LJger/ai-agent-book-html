Q*(s, a) = r + γ maxa′ Q*(s′, a′)
即时奖励折扣因子下一状态的最大价值
Q(s,a) ← Q(s,a) + α [ r + γ max Q(s′,a′) − Q(s,a) ]下划线 = TD 目标；减去当前估计 = TD 误差
状态 s：储藏室（持有：空）动作 a：拿红钥匙奖励 r：+5s′：储藏室（持有：红钥匙）max Q(s′, a′) = 0.63（向北开门）α = 0.2 · γ = 0.99 · 旧 Q = 0.25
0.25 + 0.2 × [5 + 0.99 × 0.63 − 0.25]= 0.25 + 0.2 × [5.624 − 0.25]= 0.25 + 1.075 = 1.325
TD 误差 = 5.374 → 正向更新，Q 值大幅上升奖励向前传播：下次走到“拿钥匙”之前的状态，它的价值也会跟着上升

思考 token 是动作，先验压缩了搜索空间

路径粗细 = 概率 · 示意
思考 token：特殊的动作

不直接改变外部世界、不立即得到奖励，却能提高最终行动质量。动作表示不仅是“做什么”，还有“想多久、想什么”

预训练学到的问题解决模式
数学：识别条件 → 回忆公式 → 逐步计算编程：理解需求 → 设计结构 → 实现细节

所以即使没有额外 RL，预训练 LLM 也能生成基本的思维链

语言结构不是单独的“内部奖励”，而是策略的先验分布；RL 在它之上用真实任务奖励重新调整各条路径的概率
