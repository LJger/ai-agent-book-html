      存什么：认知科学的记忆分类
      
  
      工作记忆对应上下文窗口；长期记忆分三类，每类都能在 Agent 记忆里找到直接对应
      
  
      
    
      工作记忆Working Memory
      
    ⇄
    
      Agent 的上下文窗口处理当前任务的临时信息空间：轨迹是其中最核心的内容，也可能包含从长期记忆中激活加载的信息
      
  
      
  
      
    
      
      
      情景记忆Episodic Memory
      关于具体事件和经历的记忆
      人类“上周三和同事在那家意大利餐厅吃了一顿很棒的晚餐”
      点击看 Agent 对应
      
      
      情景记忆 · Agent
      “用户订了下周五去东京的 ANA 航班”
      记录了一个具体事件的时间、对象和细节
      
    
      
    
      
      
      语义记忆Semantic Memory
      从具体事件中抽象出的一般性知识
      人类“意大利的首都是罗马”
      点击看 Agent 对应
      
      
      语义记忆 · Agent
      “用户是素食者”
      “用户偏好靠窗座位”
      不是某次对话的记录，而是从多次交互中提炼出的稳定特征
      
    
      
    
      
      
      程序记忆Procedural Memory
      关于行为模式和流程的记忆
      人类骑自行车的能力
      点击看 Agent 对应
      
      
      程序记忆 · Agent
      先搜索直飞航班确认座位偏好使用常旅客号码订餐
      从用户反复订机票的模式中学到的通用流程
