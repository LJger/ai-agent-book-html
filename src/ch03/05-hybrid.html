图3-8 BM25：词频饱和与长度归一化

Score(Q,D) = Σ IDF(qᵢ) × TF(qᵢ,D)·(k₁+1) / ( TF + k₁·(1 − b + b·|D|/avgdl) )
朴素 TF（线性）BM25（饱和）
k₁ 饱和速度1.5
b 长度归一化0.75
|D| / avgdl1.00
词频饱和（TF）出现次数翻倍，得分不会线性翻倍
逆文档频率（IDF）“的” → IDF ≈ 0 · “量刑” → IDF ≈ 5.2
长度归一化（b）b=0 不考虑长度 · b=1 完全归一化
IDF_BM25 = ln((N − DF + 0.5) / (DF + 0.5))分子是“不含该词的文档数”；+0.5 做平滑；DF > N/2 时会变负，实现中设下限
