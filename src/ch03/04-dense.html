余弦相似度：看方向，不看长度

拖动蓝色端点二维示意
夹角—
余弦相似度—
两向量长度比—
手算示例（3 维）
“如何养猫” A = (0.9, 0.5, 0.1)“猫咪饲养指南” B = (0.8, 0.6, 0.1)“股票投资策略” C = (0.1, 0.1, 0.9)
cos(θ) = (A·B) / (|A| × |B|)
A·B = 0.72 + 0.30 + 0.01 = 1.030非常相似
A·C = 0.09 + 0.05 + 0.09 = 0.230差异很大

两篇内容相同但长度不同的文档：向量长度不同、方向一致——余弦相似度能正确判断它们语义相同
