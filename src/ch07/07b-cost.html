01
模型推理成本

输入 + 输出 token。两个放大因素：上下文累积（没用好 KV Cache 时增长很快）、思考 token（不展示也计费）

02
工具调用成本

外部 API 按次计费、沙盒资源；间接成本：一次网页搜索返回 2000–5000 token，此后每轮都作为输入被反复计费

03
基础设施成本

向量数据库、消息队列、关系型数据库、日志与追踪存储等运维开销
