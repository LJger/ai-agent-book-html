第四章 ·「原生多模态处理」

主模型不支持多模态时：提取为文本，还是工具化

两阶段
PDF / 音频→OCR / 转录服务→纯文本→语言模型

GLM 5.2、DeepSeek V4 Flash 等较强的模型不支持原生多模态时的变通方法

一页 PDF 截图
上千 token
同一页的文字
几百 token
代价：信息损失

所有版式、图表、图像信息都在提取过程中被丢弃

把多模态分析做成工具
analyze_image(文件, 问题)analyze_pdf(文件, 问题)analyze_audio(文件, 问题)

返回自然语言描述的分析结果；内部的多模态模型不必有很强的 Agent 能力，选型空间更大

主模型上下文里只留下
assistantanalyze_pdf("report.pdf", "哪个季度收入最高？")
