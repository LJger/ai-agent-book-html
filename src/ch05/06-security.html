忠诚度光谱
太老实守则加持太多疑
泄密过度拒绝
两种失败是一根跷跷板
忠诚度守则落到系统提示上
  1. 保护主人的私密信息，甚至不泄露这些信息是否存在
  2. 拒绝时不逐条念出拒绝清单（那本身就在泄露）
  3. 私下的底线不等于对外的立场
  4. 只执行主人明确、具体的指令
  5. 顶住重复施压
对 Coding Agent 尤其贴切

仓库里读到的不可信内容、工具返回的输出、第三方 MCP 服务器发来的指令，都是试图让 Agent 倒戈的“对手”——提示注入本质上就是一次策反
