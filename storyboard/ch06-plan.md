## 二、共同约定（多人并行时必须遵守）

1. **只写自己的文件**。分支不要改 `chapter.json`、本计划文件和别人的 html；完成后在汇报里给出页面清单、未覆盖项说明，由统筹汇总进本文件。
2. **页面 id** 严格按下文清单；`HOOKS['id']` 与之一致。`data-part` 按下文。
3. **样式隔离**：每页 `<style>` 的每条选择器都以 `#本页id` 开头（如 `#c06-why .xx`）；自定义 `@keyframes` 名称带本页前缀（如 `c06why-pulse`）；SVG 内 `<defs>` 的 id（渐变、marker、filter、path）带本页前缀；同一 html 文件里的类名也要带本页短前缀，避免与其他页冲突。
4. **脚本隔离**：所有页面脚本共享全局作用域——**顶层只能写 `HOOKS['id'] = {...}`**，不要写顶层 `const/let/function/class`（重复声明会让整章脚本报错）。需要的辅助函数放进钩子对象的方法里。
5. **自建图标**：`<svg width="0" height="0" style="position:absolute" aria-hidden="true"><symbol id="i-c06-文件短名-图标名" viewBox="0 0 24 24">…</symbol></svg>`，放在使用它的文件开头，id 全章唯一。
6. **出处 `.src`**：写「原书小节标题原文」（与下表一致，原样复制，含标点）+ 图号 / 实验号 / 表名；用到配套仓库真实数据时在 `.src` 或页面上写“数据：配套仓库 chapter6/目录 验收记录（日期，模型）”。
7. **示意标注**：为演示而虚构的数值、界面、对话，页面上用 `<span class="chip warn">示意</span>`（可在本页样式里把字号压到 15–16px）标出。数字只能来自原书或配套仓库记录。
8. **实验页标题**：“实验 6-N ★★：标题”（星级照原书）。真实数据不足的实验（6-1、6-10、6-12 真机部分）如实说明：配套仓库记录的状态（见第五节），演示部分标“示意”。
9. **动画与交互**：每页至少一个动态元素；概念页必须有演示；默认自动播放，点了进入手动模式；循环动画用令牌防重入；计时只用 `ctx.later / ctx.every / ctx.raf / U.wait`；`reset(s)` 恢复初始状态；同一部分内交替使用 `data-trans`（slide / zoom / flip / rise / iris）；内容多的页设 `data-dur="14000"`～`16000`。
10. **讲解 data-notes**：150–500 字，承载原书深度（推理链、限定条件、例外都保留）；加粗要点尽量原样保留并用 `<b>`。属性值里不能出现英文双引号。
11. **版式**：画布 1920×1080，主体底部不超过 y≈990；字号 ≥ 15px；中英文、数字与单位之间留空格；不用 emoji。有意滚动 / 裁切的容器加 `data-clip-ok`，有意越界的加 `data-ok-overflow`。
12. **加粗要点**：下文每页列出的加粗要点必须原文出现在本页的页面文字或讲解里（覆盖率工具做去标点、去空白的子串匹配）。
13. **检查**：写完自己的文件后跑 `node tools/build.mjs --only ch06`、`node tools/check.mjs --only ch06`、`python tools/smoke.py ch06 --quick`；只处理属于自己页面 id 的报错（其他文件可能正在被别人编辑）。最后跑一次不带 `--quick` 的完整冒烟，修掉自己页面的布局提示。不要截图。
