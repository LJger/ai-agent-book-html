# 第九章「Agent 的持续进化」制作计划（ch09）

> 原书：`upstream/book/chapter9.md`（约 2.1 万字，17 个标题，9 个实验，5 张图，3 张表，7 道思考题，77 条加粗要点）
> 参考答案：`upstream/book/reference-answers.md`「第九章」
> 配套实验：`upstream/chapter9/*/README.md` 与各项目 `validation/` 下的真实运行记录
> 输出：`src/ch09/`（页面 id 前缀 `c09-`），本章主题色 `#c084fc`

## 一、总体设计

- **主线**：一条轨迹 → 学习信号 → 选择载体（知识 / 指令 / 程序 / 参数）→ 更新提案 → 候选闸门（边界集 + 保留集）→ 灰度与回滚 → 睡眠整理 → 下一轮运行。封面、导览、各部分分隔页都围绕这条闭环。
- **全章统一配色**（各页共用，定义在 `00-opening.html` 顶部的共享样式里）：
  - 四种载体：知识 `#2dd4bf`（青绿）、指令 Prompt/Skill `#fbbf24`（琥珀）、程序/Harness `#60a5fa`（蓝，与 Harness 语义色一致）、参数 `#a78bfa`（紫，与 LLM 语义色一致）
  - 三层验证：结果层 `#34d399`（环境）、过程层 `#60a5fa`（代码规则）、质量层 LLM Rubric `#a78bfa`
  - 候选闸门：边界集 `#fb923c`、保留集 `#38bdf8`、安全集 `#fb7185`
- **共享工具**：`00-opening.html` 顶部定义 `window.C9`（自动轮播 + 点击转手动、表格高亮等小工具）和 `.c9-*` 共享样式类，后续页面直接复用。
- **真实数据**：实验页一律用配套仓库 `validation/` 的真实运行记录，并在页面 `.src` 注明来源、日期和模型；为演示虚构的数值、对话标注“示意”。
- **实验 9-4** 在配套仓库中标为 🚧（配套实现待补充），页面只演示正文给出的三臂设计、指标与发布门槛，不出现任何结果数字。
