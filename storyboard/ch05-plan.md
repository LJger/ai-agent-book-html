### 2.1 id 与类名

- 页面 id 一律 `c05-xxx`（见逐页清单）。分隔页 `c05-d1` … `c05-d9`。

| `.c5-stars` | 难度星级 ★ |

脚本（`window.C5`，在 00-opening.html 第一段脚本里定义）：

```js
C5.esc(s)                      // HTML 转义
C5.hl(src, lang)               // 单段语法高亮，lang = 'py' | 'js' | 'sql' | 'sh' | 'json'
C5.code(host, src, lang)       // 把多行代码写进 host（每行一个 <span class="ln">），返回行元素数组
C5.term(host, {max})           // 终端对象 T：T.clear()；T.line(cls, text, {type, ctx, ok, speed, html}) → Promise
C5.play(T, lines, ctx, ok, o)  // 依次播放 [{c:'cmd', t:'…', w:等待ms, type, html}]；ok() 为假即中止；返回 Promise
C5.go(id)                      // 跳到 id 对应的页面
```

`ok` 一般写成 `() => ctx.alive && tk === this.tk`。终端默认最多保留 40 行，超出自动移除最早的行（可传 `{max}`）。

### 2.3 内容与数据

- 讲解 `data-notes` 150–500 字，接近原文，保留推理链条与限定条件；原书加粗句尽量用 `<b>` 原样保留。属性值里不能有英文双引号。
- `.src` 写「原书小节标题原文」，涉及的图号、表号、实验号都写上。
- 实验页标题格式：“实验 5-N ★★：标题”。页面上同时给出：原书的实验设计（目标 / 方案 / 验收）+ 演示动画 + 配套仓库实测（如有），来源写成“数据：配套仓库 chapter5/xxx 验收记录，日期，模型”。
- **配套仓库的正式结果有多项与原书预期不同（负结果）**：如实呈现，挂 `.c5-tag.neg`，不要回避，也不要替原书圆场。见「五、实验真实数据」。
- 配套 README 的标题仍用旧编号（例如 code-for-math 写作“实验 5-1”），以 `EXPERIMENT_LEDGER.md` 的现行编号为准（5-3），页面上一律用现行编号。
- 所有自动演示：进入页面即自动播放；点击后进入手动模式（`this.auto = false`）。循环动画用令牌防重入；计时只用 `ctx.later / ctx.every / ctx.raf / U.wait`；`reset` 恢复初始状态。
- 字号 ≥ 15px；主体底部不超过 y≈990；不用 emoji。
